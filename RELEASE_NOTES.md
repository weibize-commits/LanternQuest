# LanternQuest v1.1.0

This release updates the frozen LanternQuest research code, WebXR client, analysis and figure scripts, public knowledge-graph schemas, anonymized participant outcomes, masked rater scores and aggregate evaluation data used in the manuscript. Version 1.1.0 adds the de-identified metric release and analysis code for the R3-adjudicated dynamic heritage controller benchmark and the Figure 10g source data.

The release excludes participant photographs and consent records, direct identifiers, dates and exact timestamps, raw narratives and comments, raw event logs, demographic microdata, expert-authored dynamic cases and rationales, restricted heritage media and text segments, row-level extraction predictions, trained checkpoints, credentials and local paths.
