# LanternQuest v1.0.0

This release contains the frozen LanternQuest research code, the WebXR client, analysis and figure scripts, public knowledge-graph schemas, anonymized participant outcomes, masked rater scores and aggregate evaluation data used in the manuscript.

The release excludes participant photographs and consent records, direct identifiers, dates and exact timestamps, raw narratives and comments, raw event logs, demographic microdata, restricted heritage media and text segments, row-level extraction predictions, trained checkpoints, credentials and local paths.
