# Data availability and release boundaries

This repository contains the data needed to inspect the reported aggregate results without redistributing restricted heritage sources or identifiable participant records.

## Public data

- Anonymized analysis-ready outcomes for 80 randomized participants.
- Anonymized dimension-level scores from two condition-masked narrative raters.
- Aggregate participant, expert, heritage-benchmark and extraction results.
- De-identified case-level metrics and aggregate statistics for the frozen dynamic-controller benchmark.
- Source data used for the quantitative manuscript figures.
- Weight-sensitivity results for the evidence-debt scheduler.

## Excluded data

The following files are intentionally absent: participant names and contact records; consent forms; recruitment records; dates and exact timestamps; narrative and interview text; free-text comments; raw session-event logs; participant photographs; demographic microdata; expert-authored dynamic cases; controller rationales; expert review forms; raw heritage audio, video and images; the 160 restricted extraction segments; row-level extraction predictions; trained checkpoints; API credentials; provider secrets; and local filesystem paths.

The heritage materials remain controlled by their source rights. Public access to those files is not granted by this code and data release.
